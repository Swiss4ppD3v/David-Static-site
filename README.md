#  Static Site - Projet HTML & CSS 

## À propos

Un projet pédagogique complet pour maîtriser les fondements du développement web front-end en reproduisant une maquette Figma. Ce projet couvre l'HTML sémantique et le CSS moderne pur.

---

## Prérequis

Avant de commencer, assurez-vous d'avoir installé :

- **Visual Studio Code** — Éditeur de code ([Télécharger](https://code.visualstudio.com/))
- **Navigateur moderne** — Chrome, Firefox, Safari ou Edge
- **Extension Live Server** — Pour VS Code (voir Installation)

---

## Installation

### 1. Cloner le repository

Ouvrez votre terminal et exécutez :

```bash
git clone https://github.com/username/nom-du-repo.git
cd nom-du-repo
```

Remplacez `username` par le vôtre.


### 2. Installer l'extension Live Server

Live Server permet de prévisualiser vos modifications en temps réel.

1. Ouvrez le panneau **Extensions** : `Ctrl + Shift + X` (Windows/Linux) ou `Cmd + Shift + X` (Mac)
2. Cherchez **"Live Server"**
3. Installez l'extension de **ritwickdey**


Le site se rafraîchira automatiquement à chaque modification de votre code.

## Objectifs du projet

Ce projet vous permet de :

**Maîtriser les bases de l'HTML**
- Utiliser les balises sémantiques (`<header>`, `<main>`, `<footer>`)
- Structurer correctement le contenu

**Apprendre les fondamentaux du CSS**
- Box model, Flexbox et CSS Grid

**Reproduire une maquette identiquement**
- Travailler avec les spécifications Figma
- Respecter les dimensions, couleurs et espacements
